# XSD Code Generator

## Overview

The XSD Code Generator is a comprehensive tool designed to automatically generate C# classes from ISO 20022 XSD schema files using Microsoft's xsd.exe tool. This tool streamlines the process of creating strongly-typed classes for ISO 20022 message handling.

## Features

- **Automated Class Generation**: Converts XSD files to C# classes using Microsoft's official xsd.exe tool
- **Smart Path Discovery**: Automatically finds xsd.exe across different .NET Framework SDK installations
- **Post-Processing Enhancement**: Improves generated code with proper headers, comments, and attributes
- **PowerShell Integration**: Includes automation scripts for easy usage
- **Error Handling**: Comprehensive error handling and validation
- **Cross-Platform Support**: Works with different Windows SDK and Visual Studio versions

## Usage

### Direct Tool Usage

```powershell
dotnet run --project Tools\XsdCodeGenerator [XsdPath] [Namespace] [OutputPath]
```

Example:
```powershell
dotnet run --project Tools\XsdCodeGenerator `
  Iso20022Library.Messages\Payments\Pacs\Xsd\pacs.002.001.11.xsd `
  Pacs00200111 `
  Iso20022Library.Messages\Payments\Pacs\Generated\Pacs00200111\pacs_002_001_11.cs
```

### PowerShell Script Usage

```powershell
.\Tools\XsdCodeGenerator\Generate-Classes.ps1 `
  -XsdFile "Iso20022Library.Messages\Payments\Pacs\Xsd\pacs.002.001.11.xsd" `
  -MessageType "Pacs" `
  -Version "00200111"
```

### Manual XSD.exe Usage (For Simple Cases)

When working directly in the target directory:

```powershell
# Navigate to output directory
Set-Location "Iso20022Library.Messages\Payments\Pacs\Generated\Pacs00200111"

# Run xsd.exe directly
& "C:\Program Files (x86)\Microsoft SDKs\Windows\v10.0A\bin\NETFX 4.8 Tools\xsd.exe" /c /n:Pacs00200111 "..\..\Xsd\pacs.002.001.11.xsd"
```

## Output Structure

Generated classes include:

- **Document Root Class**: Main document wrapper for the message
- **Message Classes**: Core message structure classes
- **Supporting Types**: Enums, data types, and helper classes
- **XML Attributes**: Proper serialization attributes and namespace declarations
- **Auto-Generated Headers**: Clear marking of generated code
- **XML Documentation**: Basic XML comments for IntelliSense support

## Troubleshooting

### Common Issues

1. **xsd.exe Not Found**: The tool automatically searches common SDK installation paths. If not found, install Visual Studio or .NET Framework SDK.

2. **Namespace Issues**: Use simple namespace names without special characters. The tool works best with alphanumeric namespaces.

3. **Permission Issues**: Ensure write permissions to the output directory.

4. **Path Issues**: Use relative paths from the project root or absolute paths.

### XSD.exe Path Locations

The tool searches for xsd.exe in these locations:
- `C:\Program Files (x86)\Microsoft SDKs\Windows\v10.0A\bin\NETFX 4.8 Tools\`
- `C:\Program Files (x86)\Microsoft SDKs\Windows\v10.0A\bin\NETFX 4.7.2 Tools\`
- `C:\Program Files (x86)\Microsoft SDKs\Windows\v10.0A\bin\NETFX 4.7.1 Tools\`
- `C:\Program Files (x86)\Microsoft SDKs\Windows\v10.0A\bin\NETFX 4.7 Tools\`
- Via PATH environment variable
